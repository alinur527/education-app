# Источники, скачанные материалы и права использования

Последняя фактическая проверка источников: **4 октября 2026 года**. Основной реестр — [official-source-manifest.json](../content/research/official-source-manifest.json); полное дерево и страницы — [official-curriculum.json](../content/research/official-curriculum.json). Это исследование и provenance, а не лицензия на массовое копирование внешних учебников.

## Сохранённые пользовательские входы

`content/inputs/` хранит исходные JSON/XLSX/Markdown без изменения байтов. Это каталоги ссылок, а не включённые в ZIP учебники и не готовые CMS-import пакеты. `INPUT_MANIFEST.json` проверяется offline валидатором.

## Официальная программа НЦТ

Прочитаны текущие [страница подготовки RU](https://testcenter.kz/?page_id=15094&lang=ru), [страница KK](https://testcenter.kz/?page_id=23376), [формат ЕНТ](https://testcenter.kz/?page_id=15074&lang=ru), [предметы](https://testcenter.kz/?page_id=15562&lang=ru) и [перечень групп образовательных программ с профильными парами](https://testcenter.kz/wp-content/uploads/2026/05/Список-специальностей-полной-формы-обучения-с-профильными-предметами.pdf). Прямые URL каждой из 36 спецификаций, resolved URL, SHA и страницы доступны в JSON; число пунктов по всем языковым вариантам — в [CURRICULUM_COVERAGE.md](CURRICULUM_COVERAGE.md).

Заголовки всех 36 спецификаций говорят об использовании **с 2026 года**. Их URL может содержать `2025/10`, а справочник дат истории — `2027` в имени файла: ни папка, ни имя справочника не заменяют явное правило применимости всей программы. Отдельная дата последнего изменения каждого удалённого документа не подтверждена; реестр хранит дату получения, а не выдуманный upstream update timestamp.

Сохранены и прочитаны:

| Вид | Количество | Что это означает |
|---|---:|---|
| Спецификации | 36 PDF | Официальные области содержания, разделы, темы, структура и требования |
| Официальные образцы | 16 PDF | Примеры формата; не импортированы целиком как наш банк |
| Рекомендованные книги | 15 PDF | **Перечни** учебников, не полные тексты перечисленных книг |
| Справочники | 5 PDF | Официальные дополнительные документы |
| Профильные пары | 1 PDF | Пары по группам образовательных программ |
| Каталоги/формат/предметы | 4 HTML | Текущие публичные страницы НЦТ |
| **Итого НЦТ** | **73 PDF + 4 HTML** | **20 297 831 байт** |

Каждая запись содержит `sourceId`, `url`, `resolvedUrl`, `retrievedAt`, `contentType`, `byteSize`, `sha256`, `localPath`, статус доступа и reuse policy. PDF проверены по MIME и `%PDF-`, разобраны PDF-парсером; математическая страница образца и проблемные таблицы проверялись визуально. Байты находятся в игнорируемом `test-results/source-research/`; они не считаются файлами, уже доступными пользователям приложения.

Известные дефекты исходника сохранены явно: SPEC-30:23 имеет обрезанное название на странице 2; SPEC-30:24 переписана с изображения с сохранением испорченного extraction; в SPEC-21 номер раздела перед темой 38 отсутствует и равен `null`. Наличие всех 748 кодов не снимает эти ограничения.

## Официальная схема и scoring

[exam-config.json](../content/research/exam-config.json) связывает каждое правило с URL, страницей/параграфом и датой проверки. Стандартная нетворческая схема — 120 вопросов, максимум 140, 240 минут; профиль: 25 одиночных + 5 контекстных + 5 multiple + 5 matching. Она не объявляется универсальной для специальных категорий поступающих.

Правила оценки multiple/matching прочитаны в [пункте 18 Правил проведения ЕНТ](https://old.adilet.zan.kz/rus/docs/V1700015173). Используются отдельные ID `ENT_MULTIPLE_2026_V1` и `ENT_MATCHING_2026_V1`; старые попытки не следует пересчитывать новым правилом. В частности, multiple нельзя заменять произвольным `2 − число отличий множества`. Источник и точная формула сохранены в config и [CONTENT_SOURCES_RESEARCH.md](CONTENT_SOURCES_RESEARCH.md).

Сроки регистрации 11–25 апреля и экзамена 10 мая–10 июля относятся к основному ЕНТ **2026 года** и на дату исследования уже исторические. Они не являются автоматически дедлайном следующего экзамена. `deadline.status` специально содержит `HISTORICAL_NOT_NEXT_EXAM_DEADLINE`.

## Действующее право

Для новых уроков права прочитаны официальные [RU](https://old.adilet.zan.kz/rus/docs/K2600000000) и [KZ](https://old.adilet.zan.kz/kaz/docs/K2600000000) тексты Конституции, принятой 15 марта 2026 года и действующей с 1 июля 2026 года. URL, дата действия и точные статьи каждого вопроса сохранены; [current-law-2026.json](../content/research/current-law-2026.json) содержит прочитанные отрывки. HTML не архивирован отдельным байтовым файлом, поэтому локальный SHA для него **не заявлен**.

Спецификация НЦТ могла предшествовать этому изменению закона. Её оригинальный текст не переписывался; старые номера статей, формулировки и органы требуют review перед использованием в текущих задачах. Историческое упоминание Конституции 1995 года в программе истории сохраняется именно как историческое.

## Авторские справочные источники

В каждом уроке сохранены конкретные `sourceUrls`, а во многих вопросах — дополнительные текстовые доказательства. Использованы первичные/предметные источники: e-history.kz, официальные документы Казахстана и ООН, OpenStax, British Museum/Library of Congress, USGS/NOAA, BIPM, документация Python, языковые справочники Gramota/Emle, British Council/Goethe/UT Austin и оригинальные литературные тексты. Доступность, цитирование и разрешение хранить полную копию — отдельные вопросы.

| Источник/материал | Установленное решение |
|---|---|
| PDF НЦТ | Публично скачаны для исследования; право дальнейшей перепубликации всех файлов отдельно не установлено. `EXTERNAL_LINK_UNLESS_REUSE_CONFIRMED` |
| OpenStax | Текущие страницы содержат CC BY-NC-SA и дополнительные AI-use ограничения. Нельзя маркировать книги как unrestricted CC BY; книги/иллюстрации не перепубликуются |
| e-history и современные комментарии/справочники | Прочитаны факты и контекст; публичный доступ не означает право копировать полные статьи. Original explanations/questions, ссылки на источник |
| Исторические литературные тексты | Проверяется конкретный оригинал и редакция; новый перевод, комментарий или иллюстрация не объявляется автоматически public domain |
| Авторские starter-уроки и вопросы | `AI_GENERATED`, модельные проверки, `verified=false` в release; не официальный банк НЦТ и не human approval |
| Python Tutorial 3.12.0 PDF | Явное разрешение PSF на распространение при сохранении лицензии/уведомлений; отдельный manifest ниже |

Direct retrieval некоторых страниц Gramota и ООН был недоступен; использовались доступные индексированные официальные тексты, а ограничение доступа записано в [CONTENT_SAMPLE_REVIEW.md](CONTENT_SAMPLE_REVIEW.md). Не обходились авторизация, paywall или закрытые источники. Source registry не должен превращать подобное чтение в статус «весь сайт скачан».

[python-material.json](../content/research/python-material.json) описывает неизменённый `tutorial.pdf` из [официального архива Python 3.12.0](https://docs.python.org/3.12/archives/python-3.12.0-docs-pdf-a4.zip):

- ZIP: 17 097 800 байт, SHA `8d106e12d010edc3a1fba6ed8539cd87c4da2fe87c3ed0fb3e63d64b5acf9f95`; извлечён только `docs-pdf/tutorial.pdf` без полной распаковки архива.
- Язык EN, выпуск 3.12.0, дата на обложке 7 декабря 2023; это дополнительный архивный источник.
- [PSF license](https://docs.python.org/3.12/license.html) и copyright сохранены в PDF, physical pages 136–137. Атрибуция: Guido van Rossum and the Python development team; Python Software Foundation.
- `REDISTRIBUTION_ALLOWED_WITH_NOTICES_RETAINED`; нет заявления о переводе, изменении книги, официальном одобрении приложения или антивирусном сканировании.

Исследовательский manifest намеренно фиксирует состояние до загрузки (`uploadedToApplication=false`). Фактическую загрузку, material ID и authorization test подтверждает отдельный runtime release state; нельзя менять исторический research record задним числом, чтобы имитировать проверку приложения.

## Воспроизведение

Исследование с сетью запускается оператором отдельно от CI:

```sh
python -m pip install pdfplumber openpyxl
python scripts/research_official_curriculum.py --groups specifications officialSamples officialReferences recommendedBookLists
python scripts/research_extract_curriculum.py
```

Downloader допускает только одобренные публичные HTTPS-хосты НЦТ, проверяет DNS на global IP и каждый redirect, соединяется с проверенным адресом при корректном TLS SNI; лимиты — 20 MiB/файл, 30 секунд, до 5 redirects и 3 попыток. Он не передаёт cookies, app token или proxy credentials и не исполняет документ как код. Кэш повторно используется только при совпадении URL/SHA. Пути исходного пакета и выходов заданы в исследовательских скриптах; исходники пользователя не перезаписываются.

Обычная проверка сборки полностью offline:

```sh
python scripts/validate_content.py
```

Локальная сверка всех скачанных байтов: `python scripts/validate_content.py --verify-cache`. Загрузка разрешённого PDF в CMS выполняется отдельным release CLI через защищённый API, после проверки manifest SHA и reuse policy; см. [CONTENT_RELEASE.md](CONTENT_RELEASE.md). Ни исследовательские скрипты, ни валидатор не выполняют публикацию.
